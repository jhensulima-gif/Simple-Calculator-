# Simple Calculator

A simple, clean, and functional calculator built with HTML, CSS, and JavaScript.

## Features

- Basic arithmetic operations (addition, subtraction, multiplication, division)
- Clear button to reset the display
- Delete button to remove the last character
- Decimal point support
- Keyboard support for numbers and operations
- Responsive design with a modern UI
- Error handling for invalid expressions

## How to Use

1. Open `index.html` in your web browser
2. Click the number buttons or use your keyboard to enter numbers
3. Click an operator button or use your keyboard (+, -, *, /)
4. Click the "=" button or press Enter to calculate the result
5. Use "C" to clear or "DEL" to delete the last character

## Keyboard Shortcuts

- **0-9**: Enter numbers
- **+, -, *, /**: Arithmetic operations
- **Enter**: Calculate result
- **Backspace**: Delete last character
- **Escape**: Clear display
- **.**: Decimal point

## Files

- `index.html` - HTML structure
- `style.css` - Styling and layout
- `script.js` - Calculator logic and event handling
